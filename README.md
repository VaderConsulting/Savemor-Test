# Savemor Test

C# ASP.NET MVC 4 test website for Savemor Pharmacy: category home page, product listing, cart, and store pages. The SavemorTest .NET 4.5 MVC app (Visual Studio 2012) lists top-level product categories with advertised savings on the home page, browses products by category with price-versus-recommended savings, and shows a product detail page with related/similar product placeholders. Entity Framework 5 maps Product, Category, and ProductCategory onto LocalDB files under App_Data; Simple Membership plus DotNetOpenAuth handles accounts. Open `SavemorTest.sln` in Visual Studio (restore NuGet packages from `packages.config`).
